### 备注（2026-10-29）

* **迁移编号 0027 空缺**：#38 在一次拆分中跳过了 `0027`，`0028_pack_appeals` / `0029_repository_availability_rounds` 保持原名不再重排（迁移器按文件名排序，空档不影响执行顺序）。已在 `0028` 文件头注明。
* **备份脚本的 Windows 可移植性问题**：`scripts/backup.mjs` 用 `tar -czf ... -C <绝对路径>` 打包媒体；在 Git-Bash/GNU tar 下 `C:...` 会被当成远程主机（`Cannot connect to C: resolve failed`），把 Windows 自带 `tar` 放到 PATH 最前即正常。线上 Linux 不受影响；若要让 Windows 也能跑，建议改用 `tar --force-local` 或纯 Node 打包。

## 变更规则

1. 新条目**追加**，编号+1，不改旧条目；
2. 推翻旧决策时，新条目里写「取代第 N 条」，并在第 N 条末尾加一句「已被第 M 条取代」；
3. 每条都要能被代码验证：写清迁移号 / 模块 / 路由，别只写"已讨论"；
4. 与 `idea.md` 冲突的决策**不合法** —— 要么改 `idea.md`（并说明），要么改决策。
